1. Project Title & Internship Details

SpendWise is a modern, offline-first personal finance and expense tracking application engineered for students and early-career professionals. Built as the Week 02 project for the Stack & Scale Remote Internship 2026, SpendWise empowers users to monitor their income, track daily expenditures, set monthly category spending caps, and visualize savings progress without cloud dependencies, paid APIs, or third-party bank logins.

3. Overview of Premium Fintech UI Design

SpendWise was designed from the ground up to match the visual fidelity of tier-one fintech applications. The visual direction features:

  • Brand Identity: Distinctive violet/purple brand identity (#6536C7) complemented by deep purple accents (#4F28A4) and lavender surfaces (#F8F6FE, #F6F4FC).

10. Challenges Encountered & Solutions

  • Challenge 1 (Host Disk Space Exhaustion): During the initial build, Windows reported a disk-full error (OS Error 112).
    Solution: Cleaned system temp caches and emptied the Recycle Bin, recovering over 2.5 GB of free space and unblocking the compiler.
  • Challenge 2 (Material 3 CardTheme Compatibility): In modern Flutter (v3.47+), assigning a legacy CardTheme to cardTheme triggered a type mismatch lint.
    Solution: Updated the theme configuration to use CardThemeData in full alignment with the latest Flutter Material 3 SDK.
  • Challenge 3 (Desktop vs. Mobile SQLite Support): Standard sqflite requires native Android/iOS channels and can fail when running standard Dart unit tests or Windows desktop builds.
    Solution: Integrated sqflite_common_ffi and implemented dynamic platform detection in AppDatabase, allowing desktop runners and in-memory unit tests to execute SQLite queries flawlessly.
